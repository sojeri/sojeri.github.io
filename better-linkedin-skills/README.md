# better linkedin skills

## To update skills

1. Painstakingly copy from linkedin into the `data/data.json` file
2. Open `data/transform-skills.js` in node
3. Run `saveAggregateSkills()`
4. Commit changes to `skills.json` and push them to github*
5. Refresh the local or live version

\* = because CORS. have to fetch from a live server and this was the laziest way I found to do that
